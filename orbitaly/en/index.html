How it's built

Full-stack app built with React and TanStack Start (server-side rendering), Supabase (PostgreSQL with row-level security, auth and realtime), Tailwind CSS and Capacitor for Android. It connects live to TMDB, IGDB, Deezer, Apple Music, Spotify, Google Books, Open Library, Kitsu and AniList, with relevance ranking, caching and rate limiting. Interface in 9 languages.
